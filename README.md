# 知学管家 AI Study Coach

一个**个人用的 AI 学习平台**：导入学习资料 → 基于资料问答（带真实引用）→ 整理知识点 → 生成练习题 → 记录错题 → 安排复习 → 检验学习效果。

- 面向单个用户，数据全部保存在本机（SQLite），不上传到任何服务器。
- AI 功能通过 **OpenAI 兼容接口**接入任意模型平台（智谱 / DeepSeek / Kimi / 通义 / SiliconFlow 等），API Key 只保存在服务器端 `.env` 中。
- 检索用纯 JS 实现的 BM25 关键词检索，第一版**不依赖向量数据库**，安装即用。

## 一、安装与启动（从零开始，Windows）

### 第 1 步：安装 Node.js

到 https://nodejs.org 下载并安装 **Node.js 22 LTS**（安装时一路下一步即可）。
验证：按 `Win+R` 输入 `cmd` 回车，在黑窗口输入：

```bat
node -v
```

显示 `v22.x.x` 即可（本项目的中文复习数据等功能依赖 Node 22 内置的 SQLite，低于 22.5 无法运行）。

### 第 2 步：进入项目目录并安装依赖

打开命令行（CMD 或 PowerShell），执行：

```bat
cd /d E:\Users\luo17\AppData\Programs\Zcode\study-coach
npm install
```

> 国内网络较慢时，可先执行 `npm config set registry https://registry.npmmirror.com` 再 `npm install`。

### 第 3 步：配置模型 API Key

1. 把 `.env.example` 复制一份，重命名为 `.env`（注意不是 `.env.txt`）；
2. 用记事本打开 `.env`，把 `AI_API_KEY=` 后面改成你自己的 Key，例如：

```ini
AI_API_KEY=在这里粘贴你的Key
AI_BASE_URL=https://open.bigmodel.cn/api/paas/v4
AI_MODEL=glm-4-flash
```

3. 保存并关闭。

### 第 4 步：启动

```bat
npm start
```

看到 `✅ 知学管家 AI Study Coach 已启动` 后，用浏览器打开 **http://localhost:3000** 即可使用。

停止：在命令行按 `Ctrl+C`。

## 二、如何接入你的模型平台（含赠送额度）

本项目使用 **OpenAI 兼容的 `/chat/completions` 接口**，任何提供该协议的平台都能接。修改 `.env` 里的三个变量后重启即可：

| 平台 | AI_BASE_URL | AI_MODEL 示例 | 赠送额度说明 |
|---|---|---|---|
| 智谱开放平台（默认） | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` | **glm-4-flash 模型免费**，注册即可长期白嫖，推荐新手首选 |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` | 注册送少量额度，之后按量付费（很便宜） |
| Moonshot Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` | 注册送额度 |
| 阿里云百炼（通义） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` | 新用户送大量免费 Token，含免费档模型 |
| SiliconFlow 硅基流动 | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-7B-Instruct`（免费档） | 部分小模型免费，注册送额度 |
| OpenRouter | `https://openrouter.ai/api/v1` | 按平台文档填写 | 部分模型带免费额度 |

**获取步骤（以智谱为例）：**

1. 打开 https://open.bigmodel.cn → 注册/登录；
2. 进入「API Keys」页面 → 新建一个 API Key 并复制；
3. 粘贴到 `.env` 的 `AI_API_KEY=` 后面；
4. `npm start` 重启，进入网页的「设置」页点 **测试模型连接**，显示 ✅ 即接入成功。

> 平台注册页一般会标注"新用户赠送 Token"或"某模型免费"，领取后即可在本项目中使用；用完赠送额度后平台会按量计费或停止服务，用量在本项目「设置 → 模型用量」中可实时查看。

## 三、功能与页面

| 页面 | 功能 |
|---|---|
| 📊 仪表盘 | 资料/知识点/题目/练习数量、最近正确率、高频错题知识点、今日复习任务、最近学习记录（全部来自真实数据） |
| 📚 学习资料库 | 上传 PDF / TXT / Markdown（≤20MB），保留页码或章节；显示处理状态；查看、删除（级联删除衍生数据） |
| 💬 资料问答 | 选择资料后提问，RAG 先检索相关片段再回答；回答带 [编号] 引用，点击可看原文片段；资料没依据时明确说"现有资料不足以回答"，且此时不浪费模型调用 |
| 🧠 知识点笔记 | AI 依据原文整理：核心概念、关键定义、关系、例子、易错点、待确认问题，每条带来源；可重新生成、删除 |
| ✍️ 练习题库 | 按资料生成单选/多选/判断/简答题（含答案、解析、知识点、原文依据、难度）；在线练习，交卷后显示成绩与解析；作答前不泄露答案 |
| 📕 错题本 | 自动记录答错的题，按知识点/日期筛选；简答题由 AI 给评分建议、你自行确认 |
| 🗓️ 复习计划 | 答错/未掌握的知识点按固定间隔表（1→2→4→7→15→30 天）安排复习，支持"记住了/仍不熟悉/已掌握"，规则完全透明 |
| ⚙️ 设置 | 模型连接测试、Token 用量与调用记录（平台未返回用量时如实标记"未知"）、清空缓存、清空全部数据 |

**重要说明（诚实声明）：**

- 所有统计都来自你真实保存的数据，没有演示数据。
- 模型的回答质量取决于你配置的模型本身；引用编号由服务端校验（只可能指向真实检索到的片段），但内容准确性仍需你自己判断。
- 复习计划是固定规则，不保证记忆效果，只如实记录你的学习行为。

## 四、数据安全与隐私

- 所有数据保存在 `data/` 目录（SQLite 数据库 + 上传的原始文件），**不会被上传到任何地方**。
- 使用问答/整理/出题/评分功能时，**相关资料片段和你的问题会发送给你配置的模型服务商**用于生成结果（页面上也有提示）。不想让某份资料发给模型，就不要在问答/整理/出题中选择它。
- API Key 只存在于服务器端 `.env`，永远不会发送到浏览器。
- 删除资料时会级联删除它的文本片段、笔记、题目、答题记录等全部衍生数据。
- **公网/局域网部署必须设置访问密码**：在 `.env` 中设置 `APP_PASSWORD=你的密码` 后重启，打开网页需先输入密码。仅本机使用可以不设。

## 五、运行测试

```bat
npm test
```

本项目当前共 **46 个自动化测试，全部通过**，覆盖：文件上传与非法文件拒绝、PDF 文本提取与页码、分块与检索、证据不足提示、引用一致性、题目保存/答题/自动评分、错题与复习更新、API 密钥缺失处理、模型超时与异常处理、数据删除与访问控制。

测试不消耗模型 Token（AI 调用全部使用本地模拟服务）。

### AI 准确率评测（可选，需要真实 Key）

程序测试通过 ≠ 模型回答准确。本项目内置独立评测集：

```bat
npm run eval
```

它会对 `tests/eval/evalset.json` 中的 8 个问答用例 + 出题真实性用例做真实模型调用，输出"回答是否包含关键事实、是否正确引用、无关问题是否被拒答"的通过率。**换模型或换学习资料后建议重新跑一次**，结果只代表当次运行。

## 六、常见问题排查

| 现象 | 原因与解决 |
|---|---|
| `npm install` 很慢或失败 | 先执行 `npm config set registry https://registry.npmmirror.com` 再重试 |
| 启动报「端口 3000 已被占用」 | 关闭占用程序，或在 `.env` 中改 `PORT=3001` 后重启 |
| 问答/整理/出题报「尚未配置 AI 模型服务」 | 没配 `.env` 或没重启。确认 `.env` 在项目根目录、变量名正确，然后重新 `npm start` |
| 设置页「测试模型连接」失败 | 检查 Key 是否复制完整、是否过期、账户是否有余额/额度；`AI_BASE_URL` 是否与平台文档一致 |
| 上传 PDF 显示「处理失败」 | 通常是扫描版/图片型 PDF（无文字层），本版本不支持 OCR，请换文字版；也可能是加密 PDF |
| 网页打不开 | 确认命令行窗口还开着（`Ctrl+C` 会停止服务）；确认地址是 `http://localhost:3000` |
| 换了 `.env` 不生效 | `.env` 只在启动时读取，改完必须重启（`Ctrl+C` 后再 `npm start`） |

## 七、技术栈与架构

```
study-coach/
├─ server/                 # 后端（Node.js 22 + Express 4）
│  ├─ index.js             # 启动入口
│  ├─ app.js               # 路由组装与统一错误处理
│  ├─ config.js            # 环境变量/.env 加载
│  ├─ db.js                # SQLite（Node 内置 node:sqlite，无需编译）
│  ├─ ai/client.js         # 模型调用：超时/重试/用量日志/缓存（供应商无关）
│  ├─ ai/prompts.js        # 全部提示词（中文）
│  ├─ services/            # 提取(unpdf)、分块、BM25检索、引用校验、出题校验、复习调度
│  └─ routes/              # 资料/问答/笔记/题目/答题/错题/复习/仪表盘/设置 API
├─ public/                 # 前端（原生 ES Module 单页应用，无需构建）
│  ├─ index.html / css/styles.css
│  └─ js/（路由 + 8 个页面模块）
├─ tests/                  # 46 个自动化测试（node:test 内置运行器）
│  └─ eval/                # AI 准确率评测集（需真实 Key）
└─ data/                   # 运行时生成：SQLite 数据库 + 上传文件（已 gitignore）
```

- **为什么不用向量数据库？** 当前资料量级下 BM25 关键词检索简单可靠、零额外依赖；接口已抽象在 `services/rag.js`，后续需要语义检索时可平滑替换。
- **为什么前端不框架/不构建？** 减少新手维护成本，改完刷新即生效。
- 运行时依赖仅 3 个：`express`、`multer`（上传）、`unpdf`（PDF 提取）。

## 八、已知限制与下一步建议

**当前限制：**

1. 扫描版 PDF（图片型）不支持，需 OCR（可后续接入 OCR 服务）。
2. 单用户设计；虽有访问密码，但不建议把端口直接暴露到公网，推荐仅本机或内网使用，或套一层反向代理 + HTTPS。
3. 长资料整理/出题基于均匀抽样片段（结果中会注明覆盖范围），不是全文精读。
4. 简答题 AI 评分只是建议，需要人工确认；切勿把它当作客观标准。
5. 模型用量统计依赖供应商返回 `usage` 字段，不返回时如实显示"未知"。

**下一阶段建议（按优先级）：**

1. 接入 embedding 语义检索（可选混合检索），提升长资料的问答命中率；
2. 增加 OCR 支持（如 PaddleOCR 服务）；
3. 复习计划接入更完整的 SM-2/FSRS 参数；
4. 数据导出/备份（SQLite 单文件可直接复制 `data/` 目录备份）。
